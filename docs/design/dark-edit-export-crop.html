模态与控件
层级：遮罩 rgba(0,0,0,.58)；模态 SurfaceRaised #222A33，1 px #3A4552，外阴影 0 28 90 rgba(0,0,0,.7)。当前导出窗用静态浅色 fallback（Res() #FBFAF7 等），深色下必须全部改用 DynamicResource。
格式分段：轨道 #151B22；未选中透明；悬停 #26313C；选中 #2E3A47 + 1 px #56657A + 轻微内高光。选中态用“抬起的深灰”，不要用 Coral 实心，避免和主按钮抢注意力。
输入 / 下拉：底 #151B22，边框 #2C343E，文字 Ink；悬停 #202831 + #43505D；聚焦 Coral 边框 + 2 px 28% 光晕；错误 Danger #FF8E79 + 深红底提示条。
滑块：轨道 #2C343E，已填充 Coral；拇指 Coral + 2 px #0F1318；悬停 #FF8168 + 7 px 光晕；聚焦额外 2 px focus ring。质量数值保持 Ink。
复选框：未选底 #151B22 + #43505D 边框；悬停边框 Coral；选中 Coral 底 + OnCoral 勾；不要用白色勾（当前代码硬编码 White，深色 Coral 上对比不足）。
焦点顺序：关闭 → 格式 → 质量 → 调整尺寸 → 长边 → 文件名 → 复选框 → 取消 → 导出。Esc 取消，Enter 导出（仅当文件名有效）。

交互规则

  • 悬停 120 ms ease-out，按下 80 ms；只改变底色/边框/文字，不做缩放位移。
  • 键盘焦点始终可见：2 px FocusRing + 2 px 外偏移，不能只靠颜色。
  • 禁用态 opacity .38，不响应 hover；不把禁用态做成浅色块。
  • 裁剪“完成 → 导出取消”必须回到原裁剪状态；导出成功才离开裁剪模式。
  • 高对比度模式使用系统 accent、2 px 实线边框、去掉阴影与半透明。
