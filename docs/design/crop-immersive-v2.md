# 一、沉浸式裁剪

## 进入

建议在编辑面板的 Crop 区域增加一个明确的 **Crop** 按钮：

```text
[ Crop ]   Free  Original  1:1  4:3  16:9
```

点击 Crop 或任意比例 chip 后进入沉浸式裁剪模式。

不再建议把 “Crop overlay” 做成普通开关；开关只表达“显示/隐藏”，不能表达“进入一个完整的裁剪模式”。

## 沉浸式状态

进入后：

- 隐藏顶部栏、文件名 chip、dock、信息面板、胶片条、上一张/下一张箭头；
- 画布铺满窗口；
- 图片外区域压暗；
- 裁剪框保留 8 个手柄；
- 裁剪框与窗口边缘至少留 32 px；
- 手柄不会被任何浮动按钮覆盖；
- 顶部只保留两个非交互遮挡物：
  - 左上 `CROP` 标签 + `Esc` 提示；
  - 右上 `Original stays unchanged`。

底部浮动裁剪栏：

```text
┌──────────────────────────────────────────────────────────────┐
│ CROP SIZE     Free  Original  1:1  4:3  16:9     Reset  Cancel  Done │
│ 1383 × 778                                                   │
└──────────────────────────────────────────────────────────────┘
```

- 宽度约 860 px；
- 位于底部 24 px；
- 与图片底边保持 12 px 以上间距；
- 不使用右侧抽屉，避免遮住右上角手柄。

## 操作语义

| 操作 | 行为 |
| --- | --- |
| 拖动角/边 | 调整裁剪范围 |
| 内部拖动 | 移动裁剪框 |
| 比例 chip | 锁定比例并调整裁剪框 |
| Reset | 恢复整图 |
| Done | 保留当前裁剪，退出沉浸式，回到编辑面板 |
| Cancel | 丢弃本次裁剪范围，回到进入前的裁剪 |
| Esc | 等同 Cancel |
| Enter | 等同 Done |
| 方向键 | 1 px 微调；Shift = 10 px |

推荐 **Done 保留裁剪，Cancel 恢复进入前状态**；这样不会出现“退出编辑后才发现裁剪被保留/丢失”的歧义。

## 动画

- 顶部栏、dock、右侧抽屉：180 ms 淡出/收起；
- 图片：200 ms 平滑过渡到全屏画布；
- 裁剪框：不缩放、不跳动；
- 退出时反向播放。

# 二、导出预览使用裁剪结果

## 行为

点击 `Export copy…` 时：

- 使用当前 transform + crop 生成预览；
- 预览内容 = 实际将要导出的图像；
- 预览下方显示裁剪后的像素尺寸：

```text
1383 × 778 · cropped preview
```

- 预览使用完整适配（contain），不裁剪：
  - 横图显示完整横向画面；
  - 竖图显示完整竖向画面；
  - 不因预览容器的方形区域而切掉边缘。
- 如果裁剪是整图，显示：

```text
2400 × 1350 · original
```

## 预览更新时机

- 每次打开导出窗口时重新生成；
- 导出窗口是模态的，打开期间不修改裁剪；
- 关闭再修改裁剪，再打开时必须显示新裁剪；
- 不使用上一次缓存的预览图。

## 交互稿

导出窗口：

- 左侧预览显示裁剪后的星系区域；
- 尺寸说明 `1383 × 778 · cropped preview`；
- 右侧格式、质量、尺寸、文件名、元数据不变；
- 底部 Cancel / Export copy 居中。

“免费”只用于价格/授权语义，不属于裁剪比例。

# 四、实现建议

1. 编辑面板增加 `Crop` 入口，替换当前“Crop overlay”开关。
2. 增加 `CropMode` 沉浸状态，控制 chrome 可见性。
3. 裁剪浮动栏复用当前 chips、Reset、Cancel、Done。
4. 导出预览从当前 crop 重新生成 `ImageBrush.SourceRect` 或等效裁剪位图。
5. 预览容器使用 `Stretch=Uniform`，确保完整显示。
6. 中文 `L.EditFree` 固定为“自由”。
