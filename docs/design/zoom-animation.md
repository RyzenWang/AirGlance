# 缩放动画

## 目标

参考 Windows 照片和 Apple 图片查看器的缩放手感：滚轮、按钮、键盘和双击缩放
都使用短促、连续、带缓出的过渡，而不是瞬间跳变。

## 实现

- 使用 `DispatcherPriority.Render` 的 8 ms `DispatcherTimer` 驱动；
- 每帧根据经过时间计算进度；
- 缩放值在对数空间插值：

```text
zoom = from * (to / from) ^ eased
eased = 1 - (1 - t)^3
```

- 滚轮单次缩放约 130 ms；
- 双击和 1:1 切换约 280 ms；
- 滚动和缩放始终围绕指针锚点；
- 连续滚轮会从当前显示值重新瞄准新的累计目标；
- pinch 直接跟随手势，不额外插值；
- 拖动、切换图片、清理画布会立即停止动画。

## 实测

参考机器，24 MP JPEG：

- 滚轮一格：8 帧 / 127 ms，约 63 fps；
- `1` 键切到 100%：16 帧 / 255 ms，约 63 fps。

帧率由 Avalonia 渲染循环决定，动画不再依赖 100 ms 的 GIF 定时器。
